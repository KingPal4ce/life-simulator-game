# Retro Life Simulator

A NES-styled Flutter life simulator where you guide a character from birth to death, making choices that shape four core stats — happiness, health, smarts, and looks — across 100 years of life. Events and your end-of-life story are generated by Google Gemini AI.

## Setup

1. **Install dependencies**
   ```bash
   flutter pub get
   ```

2. **Create a `.env` file** in the project root:
   ```
   GEMINI_API_KEY=your_key_here
   ```
   This file must exist before running or building — it is a declared Flutter asset and its absence causes a launch error.

3. **Run the app**
   ```bash
   flutter run
   ```

## Gameplay

- Each turn you are presented with an AI-generated life event and 2–3 choices.
- Each choice applies stat deltas (clamped 0–100) to happiness, health, smarts, and looks.
- The game ends when health reaches 0, you reach age 100, or you choose to end your life early.
- On death, Gemini narrates your full life story based on the choices you made.
- Achievements unlock mid-game based on stat milestones (e.g. reaching age 80, maxing happiness).
- Your session is auto-saved via Hive and restored on next launch.

## Tech Stack

| Concern | Solution |
|---------|----------|
| State management | `provider` (`ChangeNotifier`) |
| AI events & story | Google Gemini 2.5 Flash (structured output + free-form prose) |
| Local persistence | Hive |
| UI theme | `nes_ui` (NES pixel-art style) |
| Environment config | `flutter_dotenv` |
